# sysmon

CPU 使用率・メモリ使用率・ネットワーク速度をメニューバーに常時表示する macOS アプリ。

```
▮CPU  ▮MEM   ↑ 0.35 Mbps
 5%   69%   ↓ 12.4 Mbps
```

- CPU とメモリは縦ゲージと % で表示。ゲージは 60% 未満で緑、85% 未満でオレンジ、それ以上で赤
- ネットワークは送信（↑）と受信（↓）を Mbps で表示
- 1 秒ごとに更新。値が変わってもメニューバー上の幅は変わらない
- クリックすると内訳と直近 2 分のグラフを表示
  - CPU: ユーザー / システム
  - メモリ: 使用量 / 搭載量、圧縮、スワップ
  - ネットワーク: KB/s・MB/s 表記の速度

## 数え方

- メモリはアクティビティモニタの「使用済みメモリ」と同じ（App メモリ + 確保されているメモリ + 圧縮）
- ネットワークは物理インターフェース（`en*`: Wi-Fi・有線・USB/Thunderbolt）の合計。VPN の `utun*` を足すと同じ通信を二重に数えるので除いている

## ビルド

Xcode のコマンドラインツール（`swiftc`）があればビルドできる。

```sh
./build.sh
open ~/Applications/システムモニタ.app
```

`~/Applications/システムモニタ.app` にビルドして入れ直す（起動中なら終了させてから置き換える）。

メニューの「ログイン時に起動」をオンにすると `~/Library/LaunchAgents/io.github.poporpepopo.sysmon.plist` を置き、次回ログインから自動で起動する。
